# 🔥 NewsWave — Real-Time Trending News Web App

A professional news aggregation web application built with **Java Spring Boot**.

## 🚀 Features
- Real-time India & World news
- 7 News Categories
- Top 10 Trending Section
- Search functionality
- Dark/Light Mode
- Skeleton Loading

## 🛠️ Tech Stack
- Java 17 + Spring Boot 3.5
- Thymeleaf Template Engine
- NewsAPI + NewsData.io
- HTML, CSS, JavaScript

## ▶️ How to Run
1. Clone the repository
2. Add API keys in `application.properties`
3. Run: `./mvnw spring-boot:run`
4. Open: `http://localhost:8080`
