About NewsWave

A real-time news platform built with Java Spring Boot — delivering the latest headlines from India and around the world, updated on every page refresh.

Our Mission

NewsWave was built to solve a simple problem — existing news platforms overwhelm users with too much content, ads, and distractions. We believe in delivering only the most relevant, categorized, and real-time news in a clean, professional interface. No clutter. No ads. Just news.

What is NewsWave?

NewsWave is a web-based news aggregation application that fetches live news from multiple APIs and displays them in a structured, user-friendly layout — similar to professional news portals like The Hindu or NDTV.

🔥

Trending News

The homepage features a real-time "Trending in India" section showing the top 10 latest news articles with photos, updated dynamically every time the page is loaded.

🛡️

Dual API Fallback

NewsWave uses a smart fallback system — NewsData.io for India-specific news and NewsAPI for international content. If one API fails, the other automatically takes over without any disruption.

🌙

Dark & Light Mode

Switch between dark and light themes with a single click. Your preference is saved in the browser so the same theme appears every time you visit — no need to toggle again.
